# Features Components Folder

Folder ini berisikan komponen-komponen UI yang spesifik untuk fitur-fitur tertentu. Setiap subfolder merujuk pada modul fitur Gradia:

- `auth/`: Komponen login/register (PasswordRule, OtpInput, dll)
- `dashboard/`: Widget dashboard (DueToday, Weather, TaskProgress, dll)
- `courses/`: Komponen pendukung mata kuliah (CourseCard, AddCourseForm, dll)
- `tasks/`: Komponen pendukung tugas kuliah (TaskCard, CategoryColumn, dll)
- `presences/`: Komponen pendukung presensi (PresenceCard, PresenceTable, dll)
- `calendar/`: Komponen pendukung kalender (CalendarStrip, EventList, dll)
